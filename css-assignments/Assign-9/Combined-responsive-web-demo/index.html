Responsive Design

Responsive web design makes a website adapt to different screen sizes, including desktops, tablets and mobile phones.

CSS Flexbox aligns items, CSS Grid creates rows and columns, and media queries change layouts according to screen width.

CSS Cheat Sheet

Flexbox: display: flex;
Grid: display: grid;
Transition: transition: 0.3s ease;
Media Query: @media (max-width: 700px)
